# 依赖清单

版本分两层：`package.json` 声明范围，`package-lock.json` 锁定实际安装版本。下表「实际版本」列取自本项目开发环境（`npm ci` 会严格按锁文件还原同一套版本）。

> 首次安装请用 `npm ci`（严格按锁文件），不要用 `npm install`（会按 `^` 范围升级）。更换依赖后需重新生成锁文件并提交。

---

## 一、运行环境

| 项目 | 版本要求 | 验证方式 |
|---|---|---|
| Node.js | **≥ 20**（开发实测 22.22） | `node -v` |
| npm | ≥ 10（开发实测 10.9.7） | `npm -v` |
| PostgreSQL | **16**（需 pgvector 扩展） | `select version();` |
| pgvector | ≥ 0.5 | `select extversion from pg_extension where extname='vector';` |
| Docker | 可选（仅用于起数据库） | `docker -v` |
| Git | 任意近期版本 | `git --version` |

## 五、版本锁定与升级

```bash
npm ci                     # 按 package-lock.json 精确还原
npm outdated               # 查看可升级项
npm update <pkg>           # 升级单个包后需重新验证
```

升级后必须回归的项目：

1. `npm run typecheck` + `npm run lint`
2. `npm run id:selftest`、`npm run rag:selftest`、`npm run agent:selftest`（AI 链路对 SDK 行为最敏感）
3. 若升级了 Embedding 模型或厂商，需 `npm run ai:reembed` 重建全部向量
